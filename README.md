🌟 What is Harmonic?

Harmonic is an open-source HTML media player designed for people who want a capable media player that runs directly in their browser.

No complicated setup.
No account required.
No unnecessary backend.

Just open Harmonic and play your media. 🎶

---

✨ Features

🎵 Media Playback

- ▶️ Play and pause
- ⏮️ Previous track
- ⏭️ Next track
- ⏩ Seek through media
- 🔊 Volume control
- 🔇 Mute / unmute
- ⏱️ Playback progress
- 🕐 Current time and duration
- 🎚️ Playback controls

🔀 Playback Modes

- 🔀 Shuffle
- 🔁 Repeat
- 📋 Playlist playback
- ⏭️ Automatic next-track playback

💻 Run Locally

Clone the repository:

git clone https://github.com/reyaansh72/Harmonic.git

Enter the project:

cd Harmonic

You can open the project locally using a browser or run a simple HTTP server.

🐍 Python HTTP Server

python3 -m http.server 8000

Then open:

http://localhost:8000

🎯 Project Goals

Harmonic is built around a few simple ideas:

«Powerful enough to be useful.
Simple enough to understand.
Open enough to modify.»

⚡ Fast

Keep the experience responsive and lightweight.

🧩 Simple

1. Fork the repository

2. Clone your fork

git checkout -b feature/my-feature

Improve Harmonic and test your changes locally.

5. Commit

git add .

git push origin feature/my-feature

Describe what you changed and why.

🔐 Privacy

Harmonic is designed as a browser-based media player.

When using local media, browser APIs can allow media to be handled directly on your device rather than requiring it to be uploaded to a Harmonic server.

Always check the source code and browser behavior for your particular use case.
